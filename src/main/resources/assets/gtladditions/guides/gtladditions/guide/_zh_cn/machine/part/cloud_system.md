* 云端算力供应仓等价于算力源仓，云端算力请求仓等价于算力靶仓，云端算力监控器负责监控云端算力系统的算力IO情况
* 只有带有桥接功能的多方块机器才能为云端算力系统提供算力
* 云端数据请求仓请求仓等价于数据靶仓
* 云端数据存储器负责将数据模块/数据球/闪存存储至云端数据系统，每个数据模块/数据球/闪存增加393,216EU/t的能耗，当放入创造模式数据访问仓时可为所有请求仓提供所有研究数据
