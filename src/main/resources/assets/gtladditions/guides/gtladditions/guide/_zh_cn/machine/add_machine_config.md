# GTLAdditions机器配置

大部分GTLAdditions机器的线程数默认为128（如果有；作为参照，原版跨配方并行机器为64线程）

## **均分模式**

> 均分模式下, 机器会尽可能地处理全部能处理的配方, 配方并行数尽可能平均分配 \
> 若平均分配后的总配方时间大于1000秒，配方并行数将不会平均分配转而只运行一种能处理的配方 \
> 该模式下, 总并行数为: 线程数 × 机器并行数 \
> 该模式不支持批处理

## **极限模式**

> 极限模式下, 机器会尽可能地集中处理一部分配方, 拥有无损超频和1toc(有关无损超频和1toc的概念请参考任务书) \
> 该模式下**可配置维护仓**的加成不会生效 \
> 该模式下, 线程数为最大可处理配方数 \
> 该模式会自动开启批处理，不能关闭 \
> 如无特殊说明或机制，则非跨配方并行机的GTLAdditions机器运行机制也与极限模式相同

* **可以在模组配置中选择默认模式**, 初始默认模式为**均分模式**

#### **配方最短耗时配置**

> 可以在部分GTLAdditions的机器gui左下角处打开按钮来调节 \
> 初始默认值为1s，最低为5t, 最高为10s \
> 可以在模组配置文件中修改默认值
